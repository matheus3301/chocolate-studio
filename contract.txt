ConnectionExperience.tsx
  export type ConnectionExperienceProps = ConnectionStepProps
  export function ConnectionExperience(props: ConnectionExperienceProps): JSX.Element
  Props: service, state, onRead(DeviceRead), onOffline(), onNotice(key), onPendingChange?(boolean).
  Mount enumerates only after Permissions API reports MIDI+SysEx granted, or uses already enumerated ports. Otherwise Connect Chocolate requests permission and proceeds. Exact SINCO is only a candidate profile, never identity proof. Service must qualify FootCtrlPlus_016 and complete a read. Known ambiguity/unknown ports require explicit troubleshooting pairing. Existing sessions are not switched automatically. Successful reads call onRead once per raw read ID/session; backup persistence never gates read adoption. No writes.

  onConnect opens connection UI only; reconnect never resumes a save. onVerified reports exact readback, not a replacement draft: parent retains inactive local data and stays in editor. Draft/session/read changes invalidate review, including late async preview responses. Ordinary save has no mandatory dialog. Mode-byte changes require concrete review. Original-backup failure exposes download + explicit retained-file acknowledgement only when saving is attempted. Import/restore remain in coordinator-owned HardwarePanel recoveryOnly dialog.

All new UI classes use connection-experience-, device-save-, or workbench- prefixes; coordinator owns CSS. PT/EN resources use workbenchConnection namespace. Components do not add an application header. Browser/hardware/visual qualification remains coordinator-owned.

Implementation/qualification notes
  Only new assigned files changed; the existing hardware service, transport, backup hook and broad tests remain unchanged.
  Connection pairing memory is scoped to one adapter lifetime, not persistent browser storage. Unsupported Permissions API queries fall back to Connect rather than opening a permission prompt on mount.
  Hotplug can reconnect the remembered pair, but never chooses a replacement device for an existing session. Explicit troubleshooting disconnect suspends automatic reconnection until another Connect/Refresh action.
  Save compares encoded bytes against readback, not local IDs/labels. Inactive banks are preserved by the existing mapper; unchanged data across all 13 modes is a no-op. Unsupported intent is visible and never partially written.
  No automatic write/retry follows reconnect, preview preparation, mode review, or recovery-file acknowledgement. A newer draft cannot be marked synced by an older write's completion.
  Routine copy: USB cable instruction; no read-complete announcement; verified status only Saved to Chocolate / Salvo no Chocolate. Readback/physical explanation is inside optional/exceptional review. Non-actionable labels-local warnings are omitted.
  Verification: 51 new behavioral tests passed; 107 existing connection/preview/mapping/browser-adapter tests passed. Web tsc --noEmit passed; new test files have no LSP TypeScript diagnostics.
  No hardware, browser, desktop, deployment, dependency or shared-memory writes performed. Visual/CSS, real permissions/port naming across platforms and physical hardware qualification are intentionally left to the coordinator.
