# 004 — Chocolate Plus controller layout reference

The beta.3 controller illustration is based on direct visual inspection of two
Chocolate Plus product photographs, rather than a generic set of stompbox cards:

- [Top/front product photograph](https://voltixx.co.uk/products/m-vave-chocolate-plus-wireless-midi-foot-controller-4-buttons-bt-rechargeable).
- [Physical unit in perspective](https://nafiriguitar.com/products/m-vave-chocolate-plus).

Observed anatomy: one low horizontal black chassis, A/B left, one central display
between B and C, and C/D right. Letters sit below the silver switches. E joins
A/B; F joins C/D. The user confirmed the simultaneous pair gestures. This is
visual/product evidence; it does not qualify a new configuration protocol field.

The web display identifies the editor selection. Pair labels explain simultaneous
physical presses; this release does not add programmable E/F records or send
messages when a diagram switch is selected. Per-switch assignments remain in
readable summaries outside the chassis. No vendor photo is included in the
application bundle.
